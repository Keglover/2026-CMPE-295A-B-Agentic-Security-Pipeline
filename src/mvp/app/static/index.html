How to Add More Tools

1. Register the new tool in config/tool_registry.yaml with required_args and model.
2. Add a mock executor in app/gateway/gateway_mock.py.
3. Add a real executor in app/gateway/gateway_real.py (if using cloud/local LLM).
4. Refresh this page — the tool selector auto-populates from GET /tools.
5. No frontend changes needed.
